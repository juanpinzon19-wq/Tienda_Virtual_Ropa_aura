# AURA Moda Consciente 

![AURA Moda Consciente Banner](https://endearing-crisp-f1b1ae.netlify.app/assets/hero_clothing_lookbook_1790697575080-C_VNQNTh.jpg)

**AURA Moda Consciente** es una landing page enfocada en una marca de ropa que busca el equilibrio perfecto entre estilo, bienestar y durabilidad. El proyecto destaca por ofrecer moda cómoda, prendas atemporales y tejidos transpirables que cuidan la piel, utilizando fibras naturales como algodón orgánico GOTS, lino europeo y Tencel Lyocell.

## Características de la Landing Page

- **Diseño Moderno y Minimalista:** Interfaz de usuario (UI) limpia y atemporal, reflejando los valores de la marca.
- **Totalmente Responsiva:** Adaptada perfectamente a dispositivos móviles, tablets y ordenadores de escritorio.
- **Tipografía Elegante:** Uso combinado de *Plus Jakarta Sans* (modernidad) y *Cormorant Garamond* (elegancia clásica).
- **Catálogo Esencial:** Sección de muestra de productos estrella (e.g., Pantalón de Lino Estructurado, Camiseta de Algodón Orgánico).
- **Sección FAQ (Preguntas Frecuentes):** Resolución de dudas sobre tallaje, materiales y políticas de envío/devolución.

##  Tecnologías Utilizadas

Este proyecto ha sido construido utilizando tecnologías modernas para garantizar velocidad, SEO y una excelente experiencia de usuario:

- **Framework:** React / [Vite](https://vitejs.dev/) (para un empaquetado rápido y eficiente)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/) (Clases utilitarias como `bg-[#FAF9F5]`, `scroll-smooth`)
- **Hosting / Deployment:** [Netlify](https://www.netlify.com/) (Edge / SSR)
- **Fuentes:** Google Fonts 
- **SEO & Metadatos:** OpenGraph y Schema.org JSON-LD

## Estructura de la Marca (Contenido)

La página se divide estratégicamente para la conversión de clientes:
1. **Hero Section:** Presentación del valor principal ("Ropa Cómoda y Sostenible").
2. **Colección Atemporal:** Destaca productos con descripciones enfocadas en el beneficio (transpirabilidad, ajuste superior).
3. **Sostenibilidad y Materiales:** Compromiso con fibras naturales y certificadas (GOTS).
4. **Preguntas Frecuentes (FAQ):** Manejo de objeciones (cambios gratuitos, tiempos de envío en 24-48 hrs, guía interactiva de tallas).
